# AutoAgent Test — 一页式介绍

## 它解决什么问题

测对话式 AI 产品(自家的、对手的、API 形态的、App 形态的)时,常见痛点:

- **没法批量测**:产品质量回归只能人肉一条条发,prompt 一多就跑不动
- **没法跨形态测**:同一道题想同时灌给"我们的 API、对家 App、新做的 Web 版"对比效果,每种形态都要写一套测试脚本
- **测完没留底**:回归发现退化想复现,没截图、没原始响应、没操作日志,只能"我记得当时是这样"
- **App 端尤其难**:Android App 没 API,得操作真实设备 + 抓屏 + 识别回复,工程成本高到没人愿意做

这套工具把这些事一次性收掉:**一个平台、统一界面、一份结果格式,同时覆盖 API / Web 聊天框 / Android App / 视觉 Agent 四种产品形态。**

## 它能做什么(具体)

- **批量灌 prompt**:上传一个 JSONL/CSV(几十到几万条),后台并发跑,实时进度
- **拿到的不只是文本**:每条样本都有 → 原始回复 + 全程截图 + UI 树快照 + 操作日志 + 耗时,出问题点一下就能复现
- **结果可直接拿来对比/评估**:每批一个 JSONL 结果文件,`jq` 就能切,接 Excel 也行,接评估流水线也行
- **把任意产品包装成 OpenAI API**:不管底层是 Android App 还是 Web 聊天框,平台对外都暴露 `/v1/chat/completions`,别的工具(LangChain、评估框架、内部脚本)可以无脑直连
- **Web UI 一站式**:浏览器里完成 — 配产品、上传题库、看进度、下结果、看截图、重跑失败的

## 工作原理(最短版)

```
       上传题库
          │
          ▼
   ┌─────────────┐         ┌──────────┐
   │  调度器     │ ──N并发─►│ Executor │──► 真实产品(API / 浏览器 / 手机 / Agent)
   │ (一批 = 一组)│         └────┬─────┘
   └─────────────┘              │
          ▲                     │ 回复 + 截图 + 日志
          │  实时进度(SSE)      ▼
       Web UI ◄───────── JSONL 结果文件 + SQLite 索引
```

**两个核心概念**:
- **Profile(YAML)**:描述一个被测产品 —— 是 API 就写 base_url/model;是 Web 就写 URL + 输入框/发送按钮 locator;是 Android 就写包名 + 怎么读回复
- **Executor**:对应每种形态的"执行器",负责打开目标、灌 prompt、等回复、抽文本

加新产品 = 写一个 YAML,不用改代码。

## 适合谁用

- 想做产品回归测试,但人力跟不上的算法/产品团队
- 要横向对比多个对话产品(自研 vs 竞品 vs 通用模型)的研究/评测同学
- 已有评估方法,但缺一个"稳定灌数据 + 收响应"的执行底座的人

## 它不做什么

- **不评分**:本工具负责"把回复抓回来",好坏由你自己的评估方式决定(可对接外部工具)
- **不是 prompt 编辑器**:不管 prompt 怎么写,只管把你给的 prompt 跑出去
- **不做多租户/横向扩展**:面向单团队、单机部署
